Descripción del Trabajo

Este proyecto consiste en un sistema interactivo desarrollado en C++ que permite realizar operaciones matemáticas básicas y gestionar el registro de notas de estudiantes.

El sistema fue elaborado como práctica de lógica y programación utilizando estructuras básicas del lenguaje C++.

Funcionalidades
Menú interactivo

El programa contiene las siguientes opciones:

Operaciones básicas
Registrar notas
Guardar resultados en TXT
Salir
Operaciones básicas

El sistema permite realizar:

Suma
Resta
Multiplicación
División
Validación para división entre cero
Registro de notas

El programa registra:

39 estudiantes
5 notas por cada estudiante

Y calcula automáticamente:

Promedio final
Nota mayor
Nota menor
Cantidad de aprobadas
Cantidad de reprobadas
Estado final del estudiante
Archivo TXT

Toda la información se guarda automáticamente en:

resultados.txt

Nombre del estudiante
Notas
Promedio
Estado final
Estructuras utilizadas

Variables
